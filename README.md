# 빼빼로 댄스

사진을 올리면 얼굴을 입힌 3D 빼빼로 캐릭터가 춤추는 웹페이지입니다.

- 사이트: https://bsjang89.github.io/PeperoDance/
- `index.html` 한 파일로 동작합니다 (three.js는 CDN에서 불러옵니다).
- 올린 사진은 서버로 전송되지 않고 브라우저 안에서만 사용됩니다.

## 사용법

1. "사진 올리기"를 누르고 사진을 고릅니다.
2. 얼굴 윤곽이 타원에 꽉 차도록 드래그와 슬라이더로 맞춥니다.
3. "춤추게 하기"를 누릅니다. 화면을 드래그하면 돌려볼 수 있습니다.
