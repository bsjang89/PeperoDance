# 빼빼로 댄스

사진을 올리면 얼굴을 입힌 3D 빼빼로 캐릭터가 춤추는 웹페이지입니다.

- 사이트: https://bsjang89.github.io/PeperoDance/
- `index.html` 한 파일로 동작합니다 (three.js는 CDN에서 불러옵니다).
- 올린 사진은 서버로 전송되지 않고 브라우저 안에서만 사용됩니다.

## 사용법

1. "사진 올리기"로 사진을 고르면 얼굴을 자동으로 찾아 3D 얼굴로 만듭니다.
2. "노래 넣기"로 기기에 있는 음악 파일(mp3, wav 등)을 고르면 박자와 세기를 분석해 그 노래에 맞춰 춤추고, 목소리 크기에 맞춰 입이 움직입니다.
3. 화면을 드래그하면 돌려볼 수 있고, 휠이나 두 손가락으로 확대할 수 있습니다.

노래 파일은 서버로 전송되지 않고 그 브라우저에만 저장됩니다. 공유 링크에는 얼굴만 담기고 노래는 담기지 않습니다.

## 얼굴 인식

`vendor/face_mesh/`는 Google MediaPipe Face Mesh(Apache License 2.0)의 배포 파일입니다.
사진에서 얼굴 특징점을 찾는 데 쓰이며, 브라우저 안에서만 실행됩니다.
